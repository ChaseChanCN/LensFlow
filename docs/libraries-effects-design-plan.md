# LensFlow · Libraries.dev 交互效果接入计划

日期：2026-10-16 · 分支：`design-system` · 状态：用户已确认预览方向，三个页面试点已实施并完成本轮检查；登录 LCP 与总产物预算未通过，详见 [试点报告](libraries-effects-pilot.md)。

**后续视觉指示：** 用户进一步要求业务页采用 `effects-preview.html` 的完整 UI。当前登录、工作台、分析页已实施深色 Material 视觉试点，见 [完整视觉试点](material-ui-pilot.md)。新的业务场景配色以该试点确认结果为准；下文浅色工作区描述为此前方案记录。

**确认后的调整：** Beam 每次挂载独立随机选择五种形态之一、四种色彩之一；Metal 每次挂载随机选择三种材质之一。随机结果在重渲染时保持稳定，允许连续两次恰好相同。强度固定为 0.7。Gooey 的加号使用 SVG 几何居中，不再依赖字形基线。预览保留形态/材质手动比较，移除强度滑块；业务页面不暴露装饰参数。

## 1. 目标与流程

将 Beam、Orb、Gooey、Metal 纳入现有设计系统，建立统一的交互效果规则。流程为：**方案 → 独立预览 → 用户确认 → 少量页面试点 → 用户确认试点 → 全站迁移 → 验收**。预览方向已获确认，当前推进 LoginPage、AnalysisResultPage 和 DashboardPage 试点；全站迁移在试点验收与确认之后进行。

保留现有品牌蓝灰、浅色业务工作区、中性照片处理区。装饰效果不改变 API、角色权限、订单状态机、文案含义或键盘操作。P5 既有阻断独立保留，详见 [原验收报告](design-system-phase-5.md)。

## 2. 库与角色

已核对官方文档与 npm 元数据；安装时固定版本，React 19 满足各库 React 18+ 要求。四包 npm 元数据均为 MIT，无声明的运行时 dependencies；实际脚本体积、GPU 和 RAF 成本仍需测量。

| 库 | 版本 | LensFlow 用途 | 默认规则 |
|---|---|---|---|
| `border-beam` | 1.4.1 | 关键卡片、AI 处理中边界、获得焦点的重点入口 | 挂载时随机形态/色彩，固定强度 0.7；同屏最多 2 个活动效果 |
| `thinking-orbs` | 0.3.2 | AI 分析进行中与相关阶段说明 | 64px 空间型状态，20px 行内状态；保留可朗读文字，不替代真实进度 |
| `liquid-gooey` | 0.2.2 | 可展开的局部快捷操作组 | blur 6 / contrast 18；显式展开，次要项折叠时不可聚焦；不用于普通表单或破坏性确认 |
| `metal-fx` | 2.0.11 | 品牌主 CTA、少量强调操作、展示徽章 | 挂载时随机 chromatic/silver/gold；固定强度 0.7；页面最多 1 个实时 WebGL 实例 |

Orb 状态映射：connecting=建立分析连接，searching=查找素材，working=常规处理，solving=分析质量，weaving=整理关联，composing=生成结果，shaping=优化结果，listening=等待输入，breathing=空闲。只由真实业务状态驱动；预览明确标注为模拟，不伪造分析进度。

普通按钮、表单、导航保持原有语义和可读性；所有适用场景通过共用效果封装接入这些库。不会给每个按钮叠加全部效果。Beam 与 Metal 不在同一个按钮同时运行，Gooey 只控制菜单背景/位置，文本保持清晰。

## 3. 预览设计

独立入口：`/effects-preview.html`，不引入业务 App 路由、不发送业务 API。

- 品牌编辑式页头、冷蓝灰强调、真实库渲染的 Metal 主按钮。
- Beam 卡片：尺寸、配色和强度可调；展示四种库的实际效果，不用 CSS 仿造。
- Orb：九种状态与两种尺寸可选，同时保留中文状态文字。
- Gooey：可展开的作品快捷操作，支持点击、键盘和 Escape，操作只更新示例反馈。
- 浅色/深色切换、统一暂停、减少动态效果模拟；系统偏好优先；页面隐藏自动暂停；强度按用户确认固定为 0.7。
- 响应式布局，375/768/1440px；控件拥有标签、明确焦点和不少于 44px 的触达区域。

预览确认点：整体克制程度、默认配色、金属主按钮、Orb 观感、Gooey 的位置和展开方向。确认后记录参数，再开展试点。

## 4. 封装与动态效果策略

试点时建立 `components/effects` 封装：统一强度、尺寸、主题、可见性、暂停与回退；基础 Button/Input 等的业务语义保持由现有组件负责。重型效果使用按需加载，Metal 不进入所有页面的公共首屏包。

暂停来自三种来源：用户暂停、`prefers-reduced-motion`、页面不可见。Beam 设置 active=false，Orb/Metal 设置 paused。Gooey 在减少动态效果或暂停时改用静态、无过渡的操作组，仍可访问全部操作。WebGL2 不可用时依赖 Metal 的普通子元素回退，实际无 WebGL 验收后才能认定通过。卸载后检查 RAF、事件监听和 WebGL 上下文释放；路由重复切换不得累计动画实例。

## 5. 试点（预览确认后）

1. **LoginPage**：主登录 CTA 的 Metal，焦点/提交态维持现有反馈；验证表单错误、自动填充、Enter 提交。
2. **AnalysisResultPage / 上传后的分析区域**：Orb + 一个低强度 Beam，使用现有 loading/analysis 状态；错误与空状态仍明确展示。
3. **DashboardPage**：局部 Gooey 快捷操作组，功能仍由现有导航执行；不给每个统计卡片加动画。

试点前保存当前页面截图、构建体积、同配置性能与交互基线；先单页接入，再以三个页面整体评估。用户确认后冻结封装与参数。存在既有业务阻断的路径用明确夹具隔离视觉验收，同时保留真实接口回归失败，不将模拟成功计入端到端通过。

## 6. 全站迁移（试点确认后）

按认证 → 摄影师工作区 → 客户端 → 品牌页批次迁移。逐页登记效果用途、活动实例数、回退方式和验收结果。照片像素区域不叠光效；错误、删除等高风险操作保持清晰语义。保留统一开关，可逐页回退至基础控件。旧效果清理在对应批次验收之后执行。

## 7. 验收计划与门禁

### 每一阶段记录

记录提交/工作树版本、依赖锁、浏览器/系统/设备、测试时间、动效偏好、性能设置、全部原始样本与截图。自动化结果、人工结果和未测项目分列。

| 类别 | 方法 | 通过条件 |
|---|---|---|
| 构建与类型 | npm run build；类型检查 | 无新增错误；依赖锁一致 |
| 单元与组件 | 用户已要求后续验收：补充暂停/回退/卸载/折叠焦点测试，全量回归 | 新增测试和原有测试全部通过，核心组件行覆盖 ≥90% |
| 视觉 | 三宽度 × 浅/深色 × 普通/减少动态效果；逐页截图复核 | 无横向溢出、裁切、遮挡；文本清晰；照片内容不被光效污染 |
| 键盘 | Tab/Shift+Tab/Enter/Space/Escape | 焦点可见、菜单可关、折叠项不聚焦、不抢表单焦点 |
| 读屏 | NVDA/Edge 或 Narrator；记录版本及实际朗读 | 状态文字正确，装饰 Canvas/SVG 不重复播报，无假进度，错误可感知 |
| 对比度 | 文字和控件状态测量 | 普通文字 ≥4.5:1，大字 ≥3:1，焦点/必要边界 ≥3:1；发光不作为唯一提示 |
| 动效 | 系统偏好、用户开关、隐藏标签页、重复挂载 | 减少动态效果默认静态；暂停后装饰停止；状态信息仍可访问；无 RAF 累积 |
| WebGL 回退 | 禁用 WebGL2、模拟上下文丢失 | 普通按钮仍显示、可聚焦、可点击；无空白阻断 |
| 浏览器 | Edge/Chrome/Firefox 桌面、真实 Safari/iOS | 所有效果与回退可用；未具备的环境标记待测，不能以 Chromium 代签 Safari |
| 真实功能 | 登录、预约、上传分析、选片、修图、下载、角色隔离 | 请求/状态保持正确；P5 阻断修复前全系统不得签收 |
| 性能 | 同设备/同设置前后各 3 次交替采样，使用中位数 | Lighthouse 不低于阶段基线 5 分；FCP/LCP 不增加 >20%；交互期间主线程无新增 >200ms 长任务 |
| 体积 | 原始及 gzip、路由分块测量 | 公共首屏 gzip 增量 ≤10KB；试点路由 gzip 增量 ≤50KB；总产物相对阶段前 ≤10%，超出则拆包/降级后复验 |
| 稳定性 | 20 次路由切换/挂载卸载，隐藏恢复；记录 RAF 与上下文数 | 无未处理异常、无持续增长的动画实例或 WebGL 上下文 |

### 签收节奏

- **预览签收**：用户选择视觉方向、强度、场景映射；不代表业务页面验收。
- **试点签收**：三页功能、视觉、键盘、动效与性能门禁通过；提交截图和逐项报告，等待用户确认后迁移全站。
- **全站签收**：页面清单全覆盖、实际浏览器/读屏和真实业务回归完成，已知失败归零或由用户明确接受；交付机器结果、人工记录、体积对比和回退说明。
