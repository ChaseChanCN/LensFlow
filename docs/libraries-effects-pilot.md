# Libraries.dev · 三页试点

日期：2026-10-16 · 分支：`design-system`

**状态：预览方向已获确认，试点已实现；尚未签收全站迁移。** 试点功能与交互检查已执行，性能和资源预算逐项记录在 [机器结果](libraries-effects-pilot-results.json)。原 P5 的权限、业务流程与人工读屏待办继续保留。

## 已按反馈调整

- Beam：每个组件实例挂载时随机选择 5 种光效形态之一、4 种色彩之一，普通重渲染不重选。
- Metal：每次挂载随机选择 chromatic / silver / gold，强度固定 0.7。
- Beam 强度也统一为 0.7；预览移除了强度滑块，保留形态、配色、材质比较。
- Gooey：加号改为对称 SVG 路径，按钮使用 grid 居中并清除 padding。浏览器测得图标与按钮中心纵向误差约 0.000021px；不再受字体基线影响。

随机选择允许相邻两次结果相同。偏好切换、输入、提交、请求报错等重渲染不会让材质闪变。

## 试点范围

| 页面 | 接入方式 | 保持的交互 |
|---|---|---|
| LoginPage | Metal 包裹原登录按钮 | 表单语义、Enter、原生校验、加载禁用和错误信息 |
| AnalysisResultPage | 一个 Beam 摘要区域；读取状态使用 20px Orb | 真实请求状态驱动，明确写“正在读取分析”，不伪造 AI 进度；复核 API 不变 |
| DashboardPage | Gooey 局部快捷操作组 | 订单/预约路由、鼠标展开、Tab 顺序、Escape 与焦点返回 |

已建立 `components/effects` 适配层：集中随机与强度策略、按需加载、系统减少动态效果及标签页隐藏暂停。Shader 组件在内容首次绘制后初始化，基础控件先可用。装饰渲染失败时回退到基础按钮/内容；Gooey 在静态模式提供直接操作按钮。

## 已执行验证

- 全量前端测试 **136/136**，新增 7 项适配层测试。页面业务测试隔离 Canvas/WebGL/SVG 渲染器，真实视觉另由浏览器检查，不能以 jsdom mock 证明 GPU 或浏览器兼容性。
- 业务构建与独立预览构建通过；lint 0 错误，只有原 DarkroomVideoBackground 的 2 条警告。
- 115 个令牌、121 个工具类候选、12 组文字对比、既有粒子动效脚本通过。
- 三个页面 × 375/768/1280px 共 9 个组合无横向溢出；截图留档。
- 浏览器验证 Gooey 鼠标展开、Tab 进入操作、Escape 关闭并返回加号；修复了折叠透明层挡住点击的问题。
- 隔离真实后端的登录成功跳转 `/client`；合成夹具中的分析复核显示“保留”。真实完整业务链与角色权限仍以 P5 报告中的失败为准。

## 性能与体积

首次测量后，将装饰初始化移出第一次内容绘制；保存了优化前后的全部样本。基线为本轮之前的 P5 构建，同配置桌面 Edge/Lighthouse 每页 3 次；最终版本再测每页 3 次。最终版本复测按页面顺序执行，没有宣称为同一轮交替配对。每次挂载随机效果，没有挑选最快的材质。

| 项目 | 结果 |
|---|---|
| 公共首屏 JS + CSS gzip | 约增加 1.6KB，满足 ≤10KB 预算 |
| 试点路由按需分块 gzip | 各页新增效果分块均在 50KB 内 |
| 生产文件总量 | 868,615 → 1,121,330 bytes，增加约 **29.09%**；**不满足原计划 ≤10% 总产物预算** |
| 页面性能 / FCP / LCP | 最终三次样本与逐页门禁见机器结果；不隐藏临界或失败结果 |

最终中位数如下，基线三次与最终三次分别取中位数，未对失败值向下取整：

| 页面 | 性能评分 | FCP 增幅 | LCP 基线 → 最终 | LCP 门禁 |
|---|---:|---:|---:|---|
| 登录 | 100 → 98 | +6.73% | 605.93 → 728.07ms（+20.158%） | **失败**（上限 +20%） |
| 工作台 | 100 → 99 | +10.85% | 653.66 → 735.94ms（+12.59%） | 通过 |
| 分析 | 100 → 99 | +0.11% | 688.20 → 807.16ms（+17.29%） | 通过 |

三个最终页面的三次自动无障碍审计均为 100 分，无失败规则。自动审计不代替下方人工与跨浏览器项目。

四个效果包虽然无声明的运行时依赖，仍增加约 247KB 的独立 JS 分块。按需加载控制了首屏开销，但不能视为满足总产物门禁。全站扩展前应进一步裁剪或单独确认这项预算，不能默默改阈值。

## 未完成的验收

真实 NVDA/Narrator 听读、Safari/iOS、禁用 WebGL2/上下文丢失、20 次切换的资源稳定性、交互期间长任务测量尚未签收。单元测试验证了媒体偏好变化、隐藏标签页暂停、订阅移除及渲染异常回退；没有将这些当作完整浏览器性能或读屏证据。

目前只迁移上述三个页面。后续按 [分阶段计划](libraries-effects-design-plan.md) 处理性能/体积门禁与试点确认，再全站推广。
