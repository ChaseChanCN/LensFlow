# S1-T01 华为云资源可用性验证

## 实现目的

确认华为云账号可用区域、RDS（PostgreSQL）、OBS、计算服务（CCE/ECS/FunctionGraph）、域名与 HTTPS 证书的可用性与计费条件，为 S7 部署阶段提供决策依据。若不可用，需确定本地兜底方案，确保项目开发不被阻塞。

## 如何实现

### 验证方式

需由具备华为云账号权限的人员登录控制台完成以下核查：

| 编号 | 验证项 | 验证方法 | 当前状态 |
|---|---|---|---|
| Q1 | 可用区域 | 控制台"全局设置"或 IAM 查看归属区域 | 待人工确认 |
| Q2 | RDS for PostgreSQL | 控制台 RDS 列表，查看是否可创建 PostgreSQL 实例及规格/计费 | 待人工确认 |
| Q3 | OBS 对象存储 | 控制台 OBS，尝试创建测试桶，查看计费标准 | 待人工确认 |
| Q4 | 计算服务选型 | 控制台查询 CCE/ECS/FunctionGraph 可用性 | 待人工确认 |
| Q5 | 域名与 HTTPS | 确认是否有已备案域名及 SSL 证书来源 | 待人工确认 |

### 当前环境线索

开发沙箱运行在华为云 CloudIDE 环境中（由 skill 确认），说明华为云开发环境可用。但 RDS/OBS/计算服务的配额与计费仍需人工确认。

### 本地兜底策略（已采纳）

为避免云服务不可用阻塞开发，采用以下策略：

1. **数据库**：本地开发使用 SQLite，生产切换 PostgreSQL。通过 SQLAlchemy 引擎配置实现无缝切换。
2. **对象存储**：本地开发使用文件系统，生产切换 OBS。通过 Storage 抽象层实现。
3. **部署**：本地可用 Docker Compose 完整运行；云部署在 S7 阶段根据验证结果实施。

## 改进之处

- 将云资源验证与本地开发完全解耦，符合计划书"将云资源准备与本地开发解耦"原则。
- 验证文档模板化，人工确认后只需填写"已验证/不可用"及具体结论即可。
- 数据库与存储均通过抽象层设计，切换生产环境时业务代码无需修改。

## 存在的问题

1. **无法自动验证**：当前环境无法直接调用华为云控制台 API 查询资源配额，需人工登录确认。
2. **计费风险未知**：即使服务可用，计费标准未确认，可能影响部署方案选型。
3. **域名备案周期**：若需新备案域名，周期可能较长，需尽早确认。
