# Material UI · 完整视觉试点

日期：2026-10-16 · 分支：`design-system` · 状态：**三页已实现，等待视觉确认**。

用户确认以 `effects-preview.html` 的完整视觉作为方向：背景、排版、卡片和控件一起适配材质效果。此次将该方向应用到登录、工作台、分析页，后续再分批推广。

## 视觉与结构

- **登录**：左侧品牌叙事、光线图形与大标题，右侧独立登录面板；深色输入区、明确标签、Metal 主操作。
- **工作台**：编辑式页眉、三列统计卡片、独立 Gooey 操作区、预约列表与轻量页脚。移动端统计改为紧凑纵向卡片。
- **分析**：Beam 概要卡、照片分析面板、分组指标、清晰的复核操作；单张照片展开，多张照片按卡片网格排列。
- **配色**：炭黑背景、蓝灰强调、低饱和边界，继承预览页的字体与留白；成功/警告/错误使用对应的深色语义令牌。
- **材质**：效果库通过上下文使用深色参数。Beam/Metal 每次挂载随机配置，强度固定 0.7，SVG 加号居中规则保持。

`MaterialScope` 将颜色和布局样式限定在试点范围，主题不会写入全局系统设置。已实测离开试点进入 `/orders` 时没有 `.lf-material`，仍为原有浅色背景。API、权限与状态机保持原逻辑。

## 全站推广与验收

视觉确认后按批次推进：

1. 注册与其他认证/错误页面。
2. 摄影师订单列表、详情、上传与修图工作区。
3. 客户端首页、预约/详情、选片与交付；照片本身保持中性、不叠装饰光效。
4. 统一导航、反馈与状态展示，清理本次新增的试点限定规则，形成可复用的页面与组件变体。

每批次记录响应式截图、键盘路径、加载/空/错误状态、深色对比度和全量前端回归。最终执行 [已有验收计划](libraries-effects-design-plan.md) 中的三次性能测量、实际 WebGL 回退/资源释放、读屏及跨浏览器检查。

四库的总产物预算问题仍见 [效果试点报告](libraries-effects-pilot.md)。本轮构建为 1,141,343 bytes，较前一轮效果试点增加约 1.78%；没有据此改写原有体积门槛。原 [P5 权限、业务链及人工读屏待办](design-system-phase-5.md) 继续保留。当前不宣称全系统验收通过。
