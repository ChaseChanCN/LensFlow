# S1-T08 项目文档与启动说明

## 实现目的

编写项目文档，使新开发者按文档可在干净环境启动前后端，理解架构、状态机和 API 设计，为团队协作和后续开发提供基础。

## 如何实现

### 创建的文件

| 文件 | 内容 |
|---|---|
| `README.md` | 项目说明、快速启动、项目结构、技术栈 |
| `docs/architecture.md` | 系统架构图、分层职责、设计原则 |
| `docs/state-machine.md` | 14 状态枚举、17 合法转换表、终态规则 |
| `docs/api-spec.md` | 全部 API 接口清单、统一错误格式 |

### 文档内容摘要

1. **README.md**：后端/前端启动步骤、测试命令、迁移命令、项目结构树、技术栈表。
2. **architecture.md**：ASCII 架构图（浏览器→前端→FastAPI→服务层→基础设施）、5 条设计原则。
3. **state-machine.md**：状态枚举表、合法转换表（含角色和动作）、终态规则、实现位置。
4. **api-spec.md**：按模块分组的接口清单（含角色、实现状态）、统一错误格式、HTTP 状态码表。

## 改进之处

- 所有文档无 emoji，简约风格，与页面风格一致。
- API 清单标注每个接口的实现状态和对应任务 ID，便于跟踪进度。
- 架构图使用 ASCII art，无需图片依赖，版本可控。
- README 启动步骤经过实际验证（后端 48 测试 + 前端 4 测试通过）。
