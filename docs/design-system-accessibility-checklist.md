## 操作检查

- [ ] 首页 iframe 名称、中文语言和主内容地标可识别；标题和两种角色入口读音明确，激活后到达正确页面。
- [ ] 登录、注册、预约表单逐项读出名称、必填、类型与帮助文本；日期控件可键盘操作。
- [ ] 提交空表单或错误数据时，错误与对应字段关联，焦点位置清晰，错误消息被朗读。
- [ ] 异步提交时按钮名称稳定、忙碌状态可识别；重复操作得到限制；失败可理解并重试。
- [ ] 加载、无数据、错误三类状态可区分；重试后反馈可感知，装饰性 Spinner 不重复朗读。
- [ ] Toast 成功/错误消息按适当优先级播报；不会反复打断或丢失键盘焦点。
- [ ] Modal 打开后朗读标题和内容，初始焦点合理；Tab/Shift+Tab 留在当前对话框；背景内容不可导航。
- [ ] 嵌套 Modal 仅关闭顶层；Escape 后焦点回到触发按钮；全部关闭后页面滚动与焦点恢复。
- [ ] Modal 内触发的 Toast 在 portal 环境下仍可被阅读器感知。
- [ ] 选片按钮读出照片名称与选中状态；计数更新可感知，照片网格键盘顺序合理。
- [ ] 订单状态和修图反馈不依赖颜色表达；文件输入名称与格式要求清楚。
- [ ] 成片下载的加载、成功/失败可理解；无权限或网络错误被播报，重试可操作。
- [ ] 开启系统减少动态效果后重新加载并切换偏好：粒子静态内容与入口可用，无持续动画；UI 反馈仍可理解。
- [ ] 桌面及 200% 缩放下焦点可见，浏览顺序与视觉顺序一致，无键盘陷阱。
